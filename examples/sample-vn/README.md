# Matcha Engine Sample

Checked-in Ren'Py 8 project for trying Matcha Engine end-to-end.

One character (`sakura`), four expressions — idle / happy / sad / surprised.
Character sprites are **not** committed. Starter `Placeholder` art lets you
open the project immediately; run `matcha character` to fill real poses under
`game/images/characters/` and refresh `game/matcha_characters.rpy`.

See the **Example project** section in the repo [README](../../README.md)
for the clone → generate → play recipe.
