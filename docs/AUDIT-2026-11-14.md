## Stage 1 — Self-recon: Matcha as a stranger experiences it

### The actual flow a stranger walks

| # | Step | What happens | Friction |
|---|------|--------------|----------|
| F01 | Install | `git clone` → `python3.12 -m venv .venv` → `pip install -e .` | Source-only. No PyPI, no installer, no binary |
| F02 | ComfyUI | Install ComfyUI yourself, separately, per their docs | **The cliff.** Matcha does not help here |
| F03 | Models | Download multi-GB checkpoint into the right folder; name must match YAML (or `--checkpoint`) | Manual, multi-GB, base-family matching is on the user |
| F04 | Server | Start ComfyUI with correct flags (Mac MPS has a specific flag set); health-check `curl` | Long command; mismatch = cryptic failures Matcha then has to explain |
| F05 | Dry-run | `matcha character … --dry-run` validates config + models | **Good.** Preflight lists *available* models on mismatch |
| F06 | Generate | 512×512 `--lora none`, ~15–25 min for 4 poses on MPS | Prints pose names only — no progress bar, no ETA |
| F07 | Deploy | `--deploy --project examples/sample-vn` writes images + `matcha_characters.rpy` | **Good.** Idempotent, refuses known live-game paths, warns on non-sandbox paths |
| F08 | Verify | Open in Ren'Py SDK / lint | External tool, documented |

### What is genuinely strong (do not undersell in listings) **[P3]**

- **Failure UX is the best in the competitive set.** Preflight lists the *actual available* checkpoint/LoRA names on mismatch; reject frames dump PNG + metrics JSON under `rejected/`; partial runs keep accepted poses on disk; exit codes are honest (non-zero on any failed pose; no deploy on zero images).
- **The Ren'Py last mile is real and nobody else has it:** flat or `layeredimage` definitions, cropped side-image portraits wired into `Character(image=...)`, idempotent generated `.rpy` that never touches hand-written script.
- **Honesty tooling no competitor ships:** `matcha licenses` (per-model commercial-use status, "not legal advice" stated) and `matcha disclose` (Steam survey + itch tag drafts). Turns the scariest market risk into a feature.
- **Guardrails as product:** live-game path refusal, black/NaN + smear + static-band image guards with seed retry, `--copy-only` for hand-managed games, `--poses` resume.
- Test suite is substantial and fully mocked (4 files, ~70KB; pipeline, VNCCS, quality/look-sheet, licenses).

### Friction inventory, ranked

| Rank | Friction | Evidence in code | Phase-3-relevant? |
|------|----------|--------------|-------------------|
| 1 | **ComfyUI install + model procurement is the stranger cliff.** Matcha is a thin CLI over a server the user must install, model, and start correctly | README delegates entirely; `pyproject.toml` has no installer story | Yes — **Pro packaging must answer this** (installer + preset library + verified model checklist). **[P3]** |
| 2 | **Source-only install** (`pip install -e .` from clone). Even Retro Diffusion got publicly dinged for "installs Python and Git" (see Stage 2) | `pyproject.toml`: no PyPI release, no classifiers, no license field; no `matcha --version` flag in `cli.py` | Yes — same Pro item. **[P3]** |
| 3 | **No progress/ETA signal on 15–25 min runs.** Prints pose names; README must reassure "it is not hung" | `cli.py` generation loop echoes pose name only | No — polish, post-first-dollar |
| 4 | **Verified on Mac MPS only.** Windows/Linux untested; VN devs skew Windows; CUDA IP-Adapter never retested | TIMELINE stretch items open; all smoke tests Mac | **Listing honesty** — state platform support plainly. **[P3 copy]** |
| 5 | **License catalog has 2 entries** (Anything V5, NoobAI-XL); everything else UNKNOWN | `licenses.py` `_CATALOG` | Partially — honest UNKNOWN is fine for free; a wider *verified* catalog is credible Pro value. **[P3 content, not code]** |
| 6 | **One character per YAML/run.** `MatchaConfig` multi-character project model is "reserved" | `config.py` tail | No — post-first-dollar |
| 7 | **No GUI** (explicitly deferred; parked again 2026-11-14) | STRATEGY §4 Later | No — parked |

**Stage 1 verdict:** the pipeline's *core loop is solid and its failure behavior is best-in-class*; the stranger experience breaks at the edges — installation, ComfyUI procurement, and platform coverage. Those edges are exactly what Pro packaging exists to smooth. No engine work implied.

### What users hate / love (verbatim, linked, thin sample — see header)

1. **Install friction is a named purchase-blocker even for beloved tools.** Retro Diffusion review: *"It has you install Python and Git, which for some can be pretty scary"* — and the $65 price: *"At the time of writing it's a whopping $65."* ([itch.io/post/9633234](https://itch.io/post/9633234), n=1 review — thin)
   → Matcha $19–29 sits far under the sticker-shock point; the installer directly attacks the install complaint. **[P3]**
2. **Credit/subscription fatigue is the cloud tools' exposed flank.** Scenario's own FAQ: *"Credits don't roll over."* Third-party review: *"Can be perceived as pricey for solo creators."* ([scenario.com/pricing](https://www.scenario.com/pricing); [stork.ai review](https://www.stork.ai/en/scenario-gg-asset-creator))
   → "One-time price, your GPU, no meter" is a real angle. **[P3]**
3. **Fair failure policy is a selling point strangers notice.** TavernSprite on-site survey: *"Didn't get charged for the fails either, which honestly sold me."* (n=50, self-reported, names changed — thin, vendor-hosted)
   → Matcha's analog: quality guards + free retries + reject dumps. Say it on the listing. **[P3]**
4. **Consistency is *the* pain and the backlash is real.** itch.io thread: *"you use AI to generate game assets but a warrior, a potion and a chest all end up looking like they're from 3 different games"* — and the reply: *"There's no way to achieve consistency with generative AI. Respect yourself and work with an artist."* ([itch.io/t/6518855](https://itch.io/t/6518855/do-you-struggle-with-ai-art-consistency-in-your-games))
   → Confirms STRATEGY: sell to the converted, never to artist-heavy spaces. **[P3]**
5. **VNCCS is thriving.** 1,765 stars, 115 forks, last push 2026-11-12 (two days before this audit). The July "~390 vs ~1.4k" conflict resolves **high**.
   → Wrap-don't-compete is validated — and the free generation layer keeps improving, so Matcha's value must stay orchestration + last mile. "Built on VNCCS (MIT)" is a credibility line, not a threat. **[P3 copy]** — *closes STRATEGY §8 item "VNCCS traction."*

### Positioning angles (entrepreneur format; recommend #1)

1. **For VN devs who already chose AI and are tired of subscriptions and credit meters** — Matcha is one-time, local, your GPU, and it finishes the job inside Ren'Py. *Evidence: themes 2 + 3 + matrix.*
2. **The only sprite tool that ends in your engine, not in a ZIP.** *Evidence: matrix — every competitor's "Ren'Py-ready" means transparent PNG/WEBP.*
3. **AI tooling that keeps you compliant** — license surfacing + disclosure drafts built in. *Evidence: unique column; itch de-indexing risk.*

## Stage 3 — North-star gap map ("how far from Unity-shaped?")

Unity-scale is not a feature list; it's **decades of compounding: tool → platform → ecosystem → marketplace**. Matcha is at "tool." The honest map, each item sized and gated so none of it leaks into Phase 3:

| Layer | Gap from today | Size | Gate |
|---|---|---|---|
| Tool (now) | Wedge pipeline works; edges rough (Stage 1 #1–2) | — | Phase 3 Pro packaging smooths edges |
| Tool → product | GUI/editor wrapper (parked 2026-11-14); cast/batch characters; progress UX; Windows verification | M–L | Post-first-dollar, ordered by paying-user complaints |
| Product → suite | Backgrounds/CGs; Godot/Unity formatters; preset/style packs | M each | After Pro proves repeatable sales |
| Suite → platform | Hosted/credits (Phase 4); auth/billing/abuse; then marketplace/rev-share | L | **≥ ~100 Pro sales** (existing gate) |
| Platform → ecosystem | Community, third-party LoRA/preset creators, brand gravity | Years | Compounds from Phase 3 outreach — starts now, free |
| Wildcard | MCP/agent-native interface | S–M | Only if agentic asset workflows prove real (parked 2026-11-14) |

**The Unity lesson that applies today:** Unity won by being the accessible wedge (cheap, indie-friendly) for years before it was a platform. Matcha's $19–29 one-time wedge *is* the Unity-shaped move at this stage. The ecosystem layer — the actual moat Unity has — starts compounding with Phase 3 outreach and the Civitai LoRA loop, not with engineering.
